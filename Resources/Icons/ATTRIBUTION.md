# Lucide icons

Lucide Static 1.68.0, ISC licensed. Feather-derived icons retain the MIT notice in LICENSE.txt.

Official project: https://github.com/lucide-icons/lucide
Package: https://www.npmjs.com/package/lucide-static/v/1.68.0

Native SwiftUI paths in ToolIcon.swift are generated from these unmodified SVG files. SVG elliptical arcs are expressed as cubic Bézier segments for the native renderer.
